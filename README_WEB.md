# ShopFlow 本机网页版

双击项目目录里的 **start_web.bat**，浏览器会打开 **http://localhost:5173/**。
也可以运行：

```powershell
cd D:\Code\Shopify
.\venv\Scripts\python.exe .\run_web.py
```

保持启动窗口和 AdsPower 客户端开启。关闭网页不会停止任务；停止服务或关闭电脑会中断任务，重启后可在网页重试。

新建环境固定使用 Windows 桌面版 Chrome，屏幕分辨率跟随本机，不再从所有系统中随机选到 Android / iOS 手机环境。已有环境的设备类型保存在 AdsPower 中，不会因为普通重试而重新随机生成。

打开环境后，新注册任务直接进入 `https://accounts.shopify.com/signup`；已有店铺和正在填写的注册/验证页面继续沿用，不先跳转到登录入口。

注册入口跳到已有账号的 Log in 页面时，使用本任务保存的 Shopify 密码登录，不再等待 Create account；出现 Choose an account 时只选择本任务邮箱。进入 `/accounts/.../personal` 账号资料页后，沿用当前会话查看店铺列表；若已有店铺则优先返回，列表明确显示 Create your first online store 时才点击 Create store。多个店铺且无法匹配任务店铺名时停止，不任意选择。账号资料页和邮箱未验证提示本身不代表店铺创建成功，必须进入真实店铺后台后才执行后续设置。

页面跳转导致 `Execution context was destroyed` 时，在当前页面等待预算内重新读取，不立即消耗整任务重试次数。店铺链接、名称和页面地址一次读取；读取中页面改变时重新判断当前步骤，不把读取失败当作“没有店铺”而重复创建。实际浏览器断开仍交给环境恢复流程，手动停止立即中断等待。

注册页出现 First name / Last name 时，按当前任务的联系人资料补填空白姓名栏，再等待 Create account 可用。新获取的资料保留名字和姓氏，旧资料或手动修改后的完整姓名按最后一个词作为姓氏拆分；已填写的姓名不会覆盖。姓名栏稍后出现或提交后才要求补填，也会返回表单填写，不因此刷新页面。

## 使用

1. 在 AdsPower 开启本地 API。网页自动读取原有 `config.ini`，也可以在「连接设置」修改。API Key 为空时保留原值，要删除则选「清除」。
2. 选择国家：西班牙、法国、德国、意大利、英国、美国或加拿大。自动从 `https://toolqd.com/fakename-{国家代码}` 获取姓名、街道地址、城市、州省（适用时）、邮编和电话。资料卡支持换一份和编辑，标明虚拟资料来源。
3. 在「邮箱库」选择 TXT 文件或粘贴 `邮箱----密码` 文本，点击「导入邮箱库」。默认从邮箱库取账号：单个任务下拉选择，批量填写数量并按导入顺序调用未使用邮箱，每批最多 100 条。也可切换「临时输入邮箱」沿用原有输入方式。店铺名、Shopify 密码留空会自动生成。
4. 代理选择「Cliproxy · 按国家自动取 IP」：每条开始时从短效 ISP API 提取该国家的 1 条 SOCKS5 代理，写入新建的 AdsPower 环境，自动保存 ID。首次在「连接设置」配置短效 IP API Key；保存设置不提取 IP。也可选原有网络。单个任务仍可选择已有环境，沿用它的网络配置。
5. 点击「开始任务」，在详情查看进度。需要验证码时在网页输入，或者在 AdsPower 中完成后点击继续。人机验证和无法自动处理的步骤需要你在浏览器完成。
6. 后台和设置页允许 2 分钟的慢加载；页面脚本、样式等资源持续返回时延长等待，单轮最多 5 分钟，每 30 秒记录进度，避免频繁刷新打断加载。停滞后单页最多刷新 2 次。工作台任务失败后自动重试 1 次（首次执行加重试，共 2 次）；仍失败就标记并继续下一条，不再叠加浏览器内部的整任务恢复次数。重试沿用已保存的 IP、环境、资料、密码和真实店铺地址，浏览器退出时重新打开原环境，已完成的设置步骤直接跳过。失败记录和进度保留，可在详情单独重试。手动停止可中断等待并暂停队列。浏览器内核下载会等待最多 5 分钟。

「更多选项」支持邮箱 IMAP 应用密码、指定 Shopify 密码和本机产品 CSV 路径。IMAP 登录是否可用取决于邮箱设置；不能读取时会转为网页手动验证。

只有真实店铺地址与后台导航均已出现，才会进入后续设置；Shopify 首页、登录页、加载页均不算注册完成。后台地址取自实际页面，不按任务名称推测。已保存店铺的登录失效时会等待人工恢复，不转去新建账号。

导航直接报 `ERR_CONNECTION_CLOSED`、`ERR_ABORTED` 等临时错误时，也会先执行页面恢复等待，不跳过等待连续刷新。每轮只刷新或打开目标地址一次；错误页会在等待后重新打开已保存地址。当前页面重试仍失败时先恢复当前任务，不继续请求后面的设置页。控制台日志记录发生时的状态：任务已最终失败后，浏览器后来恢复显示不会自动把未完成的设置标成成功，重试会检查并继续剩余工作。

首个后台入口和注册页每次执行最多等待 60 秒；导航超时后继续观察当前请求，到期前再检查一次页面。仍无可操作表单或首屏出现明确代理连接失败时，使用原 IP 和环境自动重试 1 次；再次失败后显示「失败已跳过」并执行下一条。任务列表显示批次序号，详情保留具体错误；HTTP 429 等响应按实际错误记录，不诊断为 IP 过期。已有店铺后台及后续设置仍使用原有单页慢加载等待规则。

已有密码页或验证页会沿用。Create account 按钮不可用时最多等待 2 分钟，可用后立即点击；点击不再附带等待导航，跳转由独立的等待逻辑检查，避免把慢跳转当作点击失败而马上刷新。按钮等待到期后会再检查一次，刚恢复可用就继续提交。若日志确认鼠标点击被页面文字层等元素拦截，且按钮仍可用、没有可见验证或模态提示，则用键盘 Enter 激活同一按钮。点击结果不确定时也先等待页面变化，约 90 秒仍停在同一密码页才自动刷新，最多 2 次。明确的输入校验错误会停止重复提交，人机验证仍需人工完成；手动停止不会触发自动续跑。

任务显示「设置未完成」时，表示必需的退货规则、书面政策或已指定的产品导入尚未完成；店铺资料提示、未填 CSV 的跳过不影响成功。普通失败自动重试 1 次，仍失败后标记「失败已跳过」，继续后续任务。手动停止会暂停队列，暂停任务单独统计，不计入「进行中」；重新启动当前任务并结束处理，或选择「跳过并继续」，才会恢复后续任务。

## 邮箱库与使用标记

- 支持 UTF-8 文本（可带 BOM），一行一个 `邮箱----密码`，每次最多 1000 个。也支持原始四段格式，只保留前两段，不把额外字段作为店铺名称。
- 邮箱密码在本机数据库中使用 Windows DPAPI 加密；普通列表、下拉框、任务接口及日志不会返回密码。
- 按导入顺序保存。相同邮箱不区分大小写；重复导入跳过已有记录，不覆盖密码、不清除使用状态。文件内同一邮箱密码冲突则整次导入失败，提示行号。
- 「未使用」：尚未执行，或已手动改回未使用，且没有任务预留；可选择或批量调用。
- 「已预留」：已加入队列，但尚未开始执行，不能被另一任务抢占。
- 「使用中」：任务已开始执行，或正在重试原任务。
- 「已使用」：已开始执行且当前没有进行中的任务；即使失败或停止也保留标记。它不等同于注册成功，实际结果请查看关联任务。
- 在邮箱库的「使用状态」列下拉选择「已使用 / 未使用」，自动保存，刷新和重启后保留。标为未使用后可重新单选或按导入顺序被批量调用；标为已使用后跳过分配。再次执行或重试后仍会自动更新状态，历史任务保留。
- 排队期间取消、尚未执行的邮箱会恢复未使用。中断任务仍保留预留，需重试或取消原任务。已预留、使用中的邮箱不可手动修改，需先结束或取消关联任务。
- 导入会匹配已有工作台任务记录；使用状态不代表邮箱在其他工具或网站中的使用情况。
- 导入及创建批次仅保存账号和任务，不提前提取 IP；当前任务成功或自动重试 1 次后仍失败，才为下一条取 IP。手动停止时暂停队列。

## 临时批量输入与进度

只填邮箱即可，例如：

```text
owner1@example.com
owner2@example.com
```

如果需要自动读验证码或指定店铺名，支持以下格式，也支持直接粘贴表格中的三列（制表符分隔）：

```text
邮箱----邮箱应用密码----店铺名
```

后两列可留空。这是「临时输入邮箱」模式的格式；四段账号文件请通过邮箱库导入。批量模式每条任务分别获取联系人资料，生成密码并创建环境，不共用预览资料或环境。整批校验通过才加入队列；重复邮箱、无效行或超过 100 条会提示具体问题，不会先运行前面的行。每批国家相同，不同国家分别提交批次。

任务按顺序执行：每条失败后自动重试 1 次，仍失败就记录原因、标记并跳到下一条；当前任务成功或用完这次重试后，才为下一条提取 IP。需要验证码或人机验证时等待人工完成；自动重试期间后续任务继续等待。执行中手动停止仍会暂停队列，不会触发自动重试。暂停状态会保存，刷新页面或重启服务不会自行恢复；恢复当前任务或点击「跳过此条，继续队列」后才继续。批量任务仅成功后关闭环境窗口，失败、自动跳过或停止时不主动关闭。任务记录可按批次查看、停止整批、重试未完成任务；也可单条处理。

## 短效 IP 与重试

- API 信息来自 [Cliproxy 短效 ISP 页面](https://dash.cliproxy.com/cli/isp-user) 的「API」栏，使用其生成的 `https://webipapi.cliproxy.com/api/getIpInfo` 接口和 `type=2` 账密格式；国家跟随任务，英国传入 `GB`。
- 每条任务开始时再提取，避免排队期间浪费短效 IP。请求数量固定为 1，提取端口在服务商要求的 443–3000 范围内分配并持久化，跳过已有任务使用或提取结果待确认的端口。旧版 20000 起始值自动迁移到合法范围。IP 额度由 Cliproxy 扣除；不自动购买或充值。
- 服务商拒绝提取时显示具体错误码和原因，密钥及代理密码会隐藏；无效端口在本地拦截。
- 提取结果立即加密保存。普通重试复用已有 IP、资料和环境，不再次提取。
- 如果提取超时、服务中断或返回内容无法识别，结果视为待确认，普通重试不会重复提取。可以在 Cliproxy 找到该条代理，在任务详情中「补录代理」后继续。
- IP 已失效时，可在停止的任务详情中点击「重新取 1 个 IP 并重试」，会消耗 1 条额度并更新原环境代理；也可以补录已有的同国家代理。
- 已验证单任务收费 IP 提取、AdsPower 环境创建和启动；重试会沿用该任务保存的 IP 与环境。真实批量注册尚未完整验证，仍受 Cliproxy 库存、短效 IP 可用性以及 Shopify 验证步骤影响。

## 本地数据

- 任务及连接设置保存在 `local_data/shopflow.sqlite3`，不会写入原有 Excel。
- 密码和任务资料使用 Windows 当前用户的 DPAPI 加密；复制到另一台电脑或另一 Windows 用户下不能直接解密。
- 网页只监听本机；API 校验本机 Host、网页 Origin 和会话令牌。端口为 5173（网页）和 8765（服务）。
- 原有 `main.py` 命令行入口保留。书面政策文案继续使用项目 `信息` 文件夹与 `config.ini` 指定表格。
- 环境创建请求若超时且结果未知，重试会先查询任务标记；没有找到时会要求绑定已有环境，不重复创建。
- 默认只处理联系人资料、退货规则、书面政策及可选产品导入，不处理主题。

## 开发与验证

需要 Windows、Node.js 22.13+、项目 `venv` 中的 Python 依赖。网页依赖已安装；迁移后在 `web` 内执行 `npm ci`。

```powershell
.\venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -p test_web_tasks.py -v
cd web
npm run typecheck
npm test
```

`tests/test_store_setup.py` 为原有浏览器回归测试，运行时需要 Playwright Chromium；也可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定本机浏览器路径。

接口参考：[AdsPower 创建环境](https://localapi-doc-en.adspower.com/docs/New-Profile-V2)、[代理配置字段](https://localapi-doc-en.adspower.com/docs/Lb8pOg)、[更新环境代理](https://localapi-doc-en.adspower.com/docs/Update-Profile-Info-V2)。
